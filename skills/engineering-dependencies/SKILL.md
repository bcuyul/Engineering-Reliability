# engineering-dependencies

Start with existing/native solutions. Compare maintained alternatives against requirements. Verify exact versions, upstream release notes, EOL, license and notices, advisories, transitive dependencies and compatibility. Prefer locked versions and isolated regression tests with rollback. No installs or upgrades without authorization.

## Español

Parte de soluciones existentes o nativas. Compara alternativas mantenidas según requisitos. Verifica versiones exactas, notas oficiales, fin de soporte, licencias, avisos, dependencias transitivas y compatibilidad. Prefiere versiones fijadas, pruebas aisladas y reversión. No instales ni actualices sin autorización.
