# Security / Seguridad

Report vulnerabilities via GitHub private vulnerability reporting if enabled. Otherwise request a private reporting channel without disclosing exploit details. Do not include credentials or private source code in public issues. The skills do not grant permissions or enforce a sandbox.

Comunica vulnerabilidades mediante informes privados de GitHub si están habilitados. En caso contrario solicita un canal privado sin divulgar detalles de explotación. No incluyas credenciales ni código privado en issues públicos. Las skills no conceden permisos ni imponen aislamiento.
