# Contributing / Contribuir

Open an issue or PR with a reproducible problem, a minimal change and evidence. Keep English and Spanish documentation aligned. Do not add dependencies or host adapters without a demonstrated need. Do not publish private data, secrets or unmeasured performance claims.

Abre un issue o PR con un problema reproducible, un cambio mínimo y evidencia. Mantén la documentación inglesa y española alineada. No añadas dependencias ni adaptadores sin necesidad demostrada. No publiques datos privados, secretos ni cifras sin medir.
