# Engineering Reliability

For engineering tasks, load the core skill when available; otherwise apply these rules. Inspect code, callers, tests and constraints before changes. Preserve existing work and contracts. Prefer existing code, platform capabilities and installed dependencies. Research new dependencies. Make the smallest complete change without cutting security, integrity, accessibility or recovery. Verify according to risk, review the diff and report evidence and gaps. Critical changes require authorization, isolation, recovery and independent review before release. Never invent results or bypass checks. These rules grant no external permissions.

## Español

Para tareas de ingeniería, carga la skill principal si está disponible; en caso contrario aplica estas reglas. Inspecciona código, consumidores, pruebas y restricciones antes de cambiar. Preserva trabajo y contratos existentes. Prefiere código existente, funciones nativas y dependencias instaladas. Investiga dependencias nuevas. Realiza el cambio completo mínimo sin sacrificar seguridad, integridad, accesibilidad ni recuperación. Verifica según riesgo, revisa el diff y comunica evidencias y carencias. Los cambios críticos requieren autorización, aislamiento, recuperación y revisión independiente antes de liberar. Nunca inventes resultados ni eludas controles. Estas reglas no conceden permisos externos.
